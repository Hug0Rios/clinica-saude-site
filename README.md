# Clínica Saúde - Site Institucional

Projeto desenvolvido em equipe com o objetivo de criar um site institucional para uma clínica de saúde.

---

## Tecnologias

* HTML5
* CSS3
* JavaScript

---

## Estrutura

* **frontend/**: contém as páginas do site, arquivos de estilo e scripts
* **docs/**: materiais de apoio e documentação do projeto

---

## Funcionalidades

* Página inicial
* Página institucional (sobre a clínica)
* Listagem de profissionais
* Apresentação de serviços
* Página de contato

## Como executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse o diretório do projeto:

```bash
cd clinica-saude-site/frontend
```

3. Abra o arquivo `index.html` em um navegador de sua preferência
